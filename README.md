# Funngro Smart Website — Assignment

A two-page React + Vite + Tailwind concept redesign for the Funngro assignment.

## Pages
- `/teen` — SEO-focused teen/student earning landing page
- `/brands` — youth marketing / company landing page

## Run
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm run preview
```

## Deploy
Deploy the repository to Vercel, Netlify, or another static host. After deployment:
1. Replace `YOUR-DOMAIN.com` in `public/robots.txt` and `public/sitemap.xml`.
2. Replace `YOUR-DOMAIN.com` in the canonical URLs inside `src/main.jsx`.
3. Add your deployed URL to the assignment remark.

## Assignment notes
This is an original concept implementation inspired by the information architecture and current public positioning of Funngro. It is not an official Funngro website.
